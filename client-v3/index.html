SCORING STANDARD

具体打分与硬触发标准

B

波动上升 + 动量转弱

B/C原始触发条件保持不变

正式硬条件：波动分位≥80% + 63日收益低于滚动中位数 + 5日收益<0，并持续3日。
C

高位小盘宽度转弱

指数仍在高位，但内部宽度恶化

正式硬条件：距20日高点≤1%、距60日高点≤3%、小盘此前参与度足够，且20日相对收益由≥0转为<0。
50

C50成交集中度

既确认B/C，也可以独立预警

  • 确认B/C：d20 = C50(t) - C50(t-20)，在此前756日分位 ≥80%，最多等待10日。
  • 独立预警：d20在此前504日分位 ≥90%，连续3日，45交易日冷却。
  • C50：当日成交额最大的前50只普通A股 / 全部沪深普通A股成交额。
融

融资余额冷却确认

只做最终过滤，不单独触发顶部

G20 = (Ft/Ft-20 − 1) / 20
G63 = (Ft/Ft-63 − 1) / 63
融资加速度 = G20 − G63
  • 与此前756个交易日比较，计算因果历史分位。
  • 分位 ≤75%：通过；>75%：最多等待3日。
  • 3日后仍>75%：过滤该候选信号。
  • 不用 ln；融资余额不是独立顶部触发器。

EVALUATION RULES

回测评价口径

顶部定义

中证全指21交易日居中局部高点；随后最多252个交易日实际最大回撤达到15%以上。

命中定义

最终预警后63个交易日内出现客观顶部，则该成熟信号记为命中。

召回定义

34个客观顶部中，有最终信号在此前63个交易日覆盖的顶部数量 / 34。

防未来函数

C50和融资历史分位只使用当天以前的数据；未来数据只用于事后定义顶部和评价结果。

87.5% / 85.3% 是当前历史回测与参数研究后的点估计，不代表未来固定成功率。正式上线后应冻结参数，用新增数据做前向验证。
